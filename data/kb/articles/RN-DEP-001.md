# Deprecation: legacy API keys

This article is for CloudFlow customers on version 3.x and 4.x.

## What changes

- Legacy API keys sent in X-CF-Key stop working on 2026-12-01.
- Until then they keep working; migrate to scoped tokens (KB-API-001).
