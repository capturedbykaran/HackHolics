# Legacy API keys (3.x)

This article is for CloudFlow customers on version 3.x.

## Using legacy keys

- 3.x uses a single account-wide API key sent in the X-CF-Key header.
- Legacy keys have full access and cannot be scoped.

## Deprecation

- Legacy API keys stop working on 2026-12-01 (see RN-DEP-001).
- Move to scoped tokens by upgrading to 4.x.
